# Robbins v. State

## Majority (PER CURIAM.)

PER CURIAM.
Upon authority of Ellis v. Outler, 25 Okla. 468, 108 Pac. 957, this cause is reversed and remanded for a new trial for failure of the defendant in error to file a brief as required by rule 7 of this court.
