# Cantwell v. Patterson

## Majority (KANE, J.)

KANE, J.
This cause was submitted for opinion on the 11th day of June, 1918, at which time the plaintiff in error was granted 20 days to file brief, the defendant in error to file his brief within 20 days thereafter. This time having long since expired, and no briefs having been filed by either party, the appeal is dismissed for failure to file briefs.
All the Justices concur.
